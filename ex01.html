Iniciando estudos DOM

Selecionando os elementos DOM

Posso selecionar os elementos DOM: Por marca (tagname);Por Id; Por classe; Por Seletor (por CSS)

Existem alguns comandos que nós vamos utilizar

por marca (tagname)

o comando é o getElementsbyTagname

Como está no plural: getElements.. eu preciso dizer o número do elemento que eu quero utilizar, lembrando que no JS, a contagem dos elementos começa no zero

por ID

o comando é getElementByID

preciso atribuir um ID na tag que eu quero manipular

por ClassName

o comando é getElementsByClassName

por seletor CSS

o comando e querySelector

Se a tag que eu quero selecionar estiver com um id, eu uso hashtag(#), mas, se tiver com uma class, eu uso ponto(.)

Selecionando por name

O comando é getElementsByName
